润色可以帮助你在任意 Mac 应用中处理选中的文本。

在 Safari、备忘录、邮件、Xcode 或你常用的编辑器中选中文字，用最顺手的方式唤起润色。文本会打开到一个轻量的转换窗口——运行操作、查看结果、复制回原处，无需把文字粘贴到单独的聊天窗口。

四种唤起方式
* 全局快捷键 — ⌃⌥R 润色，⌃⌥T 翻译
* 浮动操作条 — 选中文字后出现在旁边的小浮窗，网页浏览器中同样可用
* 服务菜单 — 右键点击选中的文本 → 服务 → 润色
* 菜单栏 — 点击魔杖图标快速访问

主要功能
* 润色选中的文本，让表达更清晰
* 将选中的文本翻译为默认或自定义目标语言
* 将中文文本转换为带声调标记的拼音
* 流式响应，实时显示生成中的输出
* 按自己的工作流调整提示词模板

自定义服务商
支持 OpenAI、Anthropic，以及任意 OpenAI 或 Anthropic 兼容接口——NVIDIA NIM、DeepSeek、Kimi、OpenRouter，或本地 llama.cpp / vLLM 服务。推理模型输出（Qwen3、DeepSeek-R1）开箱即用。

隐私
只有在你运行操作时，选中的文本才会发送给你配置的服务商。API Key 保存在 macOS 钥匙串中，绝不以明文写入磁盘。润色没有数据统计、没有远程配置，也没有任何第一方服务器。

隐私政策：https://github.com/madeye/runse-mac/blob/main/PRIVACY.md

系统要求
* macOS 15 或更高版本
* 一个你想使用的服务商的 API Key
