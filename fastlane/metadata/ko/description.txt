Runse는 모든 Mac 앱에서 선택한 텍스트를 다듬고 번역할 수 있도록 도와줍니다.

Safari, 메모, 메일, Xcode 또는 즐겨 쓰는 편집기에서 텍스트를 선택한 뒤 편한 방법으로 Runse를 실행하세요. 텍스트가 간결한 변환 창에 열리면 작업을 실행하고 결과를 확인한 다음 복사해서 붙여넣으면 됩니다. 별도의 채팅 창에 텍스트를 옮길 필요가 없습니다.

실행 방법 네 가지
* 전역 단축키 — ⌃⌥R로 다듬기, ⌃⌥T로 번역
* 플로팅 액션 바 — 텍스트를 선택하면 나타나는 팝오버로, 웹 브라우저에서도 사용 가능합니다
* 서비스 메뉴 — 선택한 텍스트를 오른쪽 클릭 → 서비스 → Runse
* 메뉴 막대 — 완드 아이콘으로 빠르게 접근

주요 기능
* 선택한 텍스트를 더 명확한 표현으로 다듬기
* 기본 또는 사용자 지정 언어로 번역
* 중국어 텍스트를 성조 표기가 있는 병음으로 변환
* 생성되는 응답을 실시간으로 스트리밍
* 나만의 워크플로에 맞게 프롬프트 템플릿 커스터마이즈

나만의 제공업체 연결
OpenAI, Anthropic 및 OpenAI·Anthropic 호환 엔드포인트를 모두 지원합니다 — NVIDIA NIM, DeepSeek, Kimi, OpenRouter, 또는 로컬 llama.cpp / vLLM 서버. 추론 모델 출력(Qwen3, DeepSeek-R1)도 별도 설정 없이 바로 사용할 수 있습니다.

개인정보 보호
작업을 실행할 때만 선택한 텍스트가 설정한 제공업체로 전송됩니다. API 키는 macOS 키체인에 저장되며 평문으로 디스크에 기록되지 않습니다. Runse에는 분석, 원격 설정, 자체 서버가 없습니다.

개인정보 처리방침: https://github.com/madeye/runse-mac/blob/main/PRIVACY.md

시스템 요구 사항
* macOS 15 이상
* 사용할 제공업체의 API 키
