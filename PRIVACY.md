# Runse for macOS Privacy Policy

Runse refines and translates selected text through the provider you configure in the app.

## Data Processed

When you run a refine, translate, or pinyin action, the selected text, selected action, and related prompt options are sent to the active AI provider so it can return a result. Provider responses and token counts may be stored locally in the app history.

## Accessibility Permission

Runse asks for macOS Accessibility access so the global hotkeys and floating action bar can read the text you selected in another app. Selected text is read on demand and is never logged or transmitted anywhere except to the active provider when you run an action.

## API Keys

Provider API keys are stored in the macOS Keychain and never written to disk in plain text. Runse may include a built-in default provider key for the default experience, and you can add your own provider keys in the app.

## Local Storage

Runse stores providers, prompts, settings, and history on your device. These records are not uploaded by Runse to a Runse-operated server.

## Third-Party Providers

AI providers process requests under their own terms and privacy policies. Only send text that you are comfortable sharing with the active provider.

## Analytics and Tracking

Runse has no analytics, no remote config, and no first-party server. It does not use advertising identifiers and does not track you across apps or websites.
